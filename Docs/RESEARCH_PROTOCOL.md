# 合成数据的真实足球迁移实验

目的：在相同真实标注预算和优化步数下，检验加入合成数据是否改善真实足球的检测和多目标追踪。提升、下降或无明显变化均如实报告。

合成来源为本轮8seed、八天气、32个4K视角，共20,116候选RGB，无号码/Pose。真实数据使用SoccerNet Tracking，按比赛隔离；保留player/goalkeeper统一为player。当前pilot两个训练比赛300帧、一个验证比赛150帧，最终test保留。尚无真实五人制标注，因此不能将公开足球结果当作真实五人制收益。

| 组 | 每epoch样本 | 独立真实标注 |
| --- | --- | ---: |
| A | COCO预训练，不微调 | 0 |
| B | 300真实图各重复2次 | 300 |
| C | 同300真实图＋300合成图 | 300 |

B/C同初始化、batch4、640输入、5epochs、750次SGD更新；seed20261021，使用last.pt。C的真实曝光次数为B一半，明确记录。合成图按seed/相机和时间分层选取，冻结清单与摘要。

A/B/C统一GPU和真实val，固定ByteTrack及阈值。检测报告AP50、AP50–95、Precision、Recall；追踪报告HOTA、DetA、AssA、IDF1、MOTA和IDSW。检测收益不等于身份关联收益。

唯一代码入口在内层experiments/sim2real，数据、权重和结果在D:/projects/FutsalMOT_Research。UE与GPU训练串行；最终test不调参。启动训练不代表已经证明合成收益。
