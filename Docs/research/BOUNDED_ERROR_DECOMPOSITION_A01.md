# 一次有边界的身份关联错误条件分解

2026-10-27，用户授权先完成一次有限错误分解，再根据完整证据只选一个因素验证。此阶段复用原结果和已验框架，不重复原54信息链、18新T评分、OC两个门槛或已有追踪/TrackEval。

## 固定来源和停止条件

原12源90个强motion_RS单元中，只有旧五场的balanced27份共同状态trace包含候选/历史/实际成本；它们与原强motion的job、MOT SHA及audit逐一对应。原三场各3个seed，旧两外部各3fold×3seed。固定读取全部27份、24863个非空高分stage调用/320752条stage-row；不混入hard27，不挑失败/active或有正负候选的行。重复状态行、fold和seed不是独立比赛。

新七场63个强motion单元缺内部trace；本轮只引用现有输出后验结果及其区间，内部原因unknown。OC的MOT/native输出同样不能替代其内部候选、确认、lost记录。低分第二关联、空成本矩阵及完整生命周期没有trace，保持unknown，不据记录行推全部帧失败率。

只做一次来源冻结、一次必要原成本分配复核和一次账本提取。若证据不足或只重复已有代理，明确不可识别并停止，不自动补跑trace、改代理、加训或搜索参数。全阶段新增模型推理、SGD、自由追踪、TrackEval、图片与测试读取均0。

## 本次新增问题及后验边界

已有信息链/决策探针说明了Pose影子评分及当前历史下的分支变化。本次新增问题是：实际强motion返回成本下，可观测困难条件主要发生在候选阶段、排序/成本界限还是全局竞争；当前历史一致身份是否已经偏离该轨迹最早的可信身份。

主值只用trace的实际`reference_cost`，不以all-gated影子logit冒充原enabled批。原stage分配从原FP32矩阵用绑定的原纯linear_assignment/lap重建，明确标记reconstructed，不用帧末`chosen_raw_UID`冒充本stage选择。先对既有首seed9份决策记录保存的`new_T.reference.assignment`逐事件比对，作为必要数值准入；不再加载新T模型或计算其分数。匹配源码是本次只读快照，缺历史逐文件SHA不补造。

GT仅后验，复用已有UID标签及政策账本的人物帧ID/候选UID，不读原GT坐标、图片或重新拟合标签。身份一致只表示当前历史观测一致，不等于整条轨迹ID正确。每track_id首次出现可信三观测历史时建立后验anchor，之后分别保留相同、混合、unknown及完整历史已转为另一ID的条件；不将该anchor当TrackEval全局最优映射，不把漂移单独判为历史更新的因果错误。

## 完整账本和观察标签

唯一键为trace SHA、frame_number、stage、track_id。每行保留联合条件：历史标签/长度、active或bbox非介入、lost_gap、当前历史ID在该帧是否存在、raw/stage/effective-gate是否有可信正候选、原实际成本、原solver单边可行性/FP32边界、最低正确/已知负/unknown成本及并列、重建全局选择及正确列是否被其他行占用、anchor状态。

若输出互斥“首个未满足条件”标签，顺序事前固定为：历史unknown或混合→当前历史ID本帧缺失→raw无可信正候选/有歧义→可信正候选未进stage→历史不足三观测或本行未介入→active行正确候选在有效gate外→正确成本不可行→选中当前历史正候选→unknown竞争→已知负例严格更优→成本并列→全局竞争/其余未识别。完整联合标志及非介入行的实际成本结果另保留；这个顺序标签不是根因或可相加的因果占比。

inactive/历史不足分层展示，不能把bbox政策行称为模型排序错误。边界按原FP32成本和实际solver判断，单列等于FP32 cutoff等情形，不自加epsilon。未匹配、歧义、未知、负结果及正确行全部保留，不只抽选可解释的错误。

## 汇总、选择与交付

每单元完整stage-row分母先核对，再按比赛内平均各匹配训练单元，原三场/旧两场分别比赛等权。复用已验t95(df=n−1)、10000次比赛bootstrap(seed20261027)及逐场留一；区间未经多比较校正，仅描述，不以行数或seed充独立样本，不设等效/非劣效δ。新七场没有内部链比例或区间，明确not_recorded。

正式账本前只读准入，运行两个有界后验CPU worker，各数值线程1，预留RAM8GiB/commit6GiB，复用来源缓存和已验worker生命周期。主智能体统筹科学取舍与实际进程，子智能体分担实现和核查。完整来源、原stdout/stderr、逐行账本、所有unknown/负值及汇总留存DResearch，独立核数与真实退出后报告阶段。

完整证据出来后只选择一个候选：若可信正确候选在可用范围内却实际排序反复混淆，才考虑候选竞争训练或一个冻结外观参考；若排序/单边可行性均满足而全局竞争失败，才考虑一个分配规则；若只有成本界限问题，才考虑一个仅由训练R确定的校准因素。历史混合或MOT未知本身不够启动算法修改。选择须说明证据范围和反证，另冻单因素协议与实际准入，不同时改多项。

当前12均已观察开发片段。后续确认泛化另锁新train/val比赛身份；最终SNMOT116/187及test包始终封存，不自动扩数据或训练轮数。此阶段关闭后不再循环同类诊断。
