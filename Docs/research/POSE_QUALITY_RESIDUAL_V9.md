# v9缺点、噪声与质量门控残差对照

目标是检验Pose在强motion_RS之上是否仍有增量，依据[训练前诊断](POSE_V9_DIAGNOSIS.md)，不预设成功。v8历史协议/数据/权重保持不变，最终116/187继续封存。

## 方法与比较

复用v8全部原始预测、窗口和顺序，motion输入仍为24个有效通道加170个零。新残差支路170→32→1，输出限制在±0.5 logit，末层零初始化，开始时与同seed的原始motion初始预测一致；motion与残差联合训练，并未冻结已经训练完的v8 motion_RS。质量为0仅保证回到本网络自己的motion分支，不保证最终权重等于旧motion_RS。

全部新组相同20098参数、初始state；`motion_residual`仅把motion特征送进残差支路，用来控制额外网络层和名义参数量。各组有效输入维度不同，不声称严格相同统计容量。Pose支路以缺失mask、坐标及其历史关系作为输入；共同有效肢体不足6时gate为0，否则按共同覆盖率和形状变化代理连续衰减。变化尺度只在该fold正例train R窗口拟合75%分位数、下限0.03，非物理噪声或可见性真值。

| 分组 | 训练输入 | 主/探索 |
| --- | --- | --- |
| motion_residual | 运动特征残差，无Pose | 主对照，三seed |
| robust | 原Pose + 20%缺点 + σ0.03 bbox尺度抖动，无质量gate | 主对照，三seed |
| gated | 与robust相同扰动，加质量gate | 主方法，三seed |
| mask | 仅51个几何mask相关通道 | 探索，预登记首seed |
| raw | 完整原Pose，无扰动/质量gate | 探索，预登记首seed |
| drop | 仅20%缺点增强 | 探索，预登记首seed |
| jitter | 仅坐标抖动增强 | 探索，预登记首seed |

每种分组都有R和RS。主3分组×3fold×3seed×2=54臂，探索4分组×3fold×首seed×2=24臂，共78个小训练。首seed固定20261024，不是结果最好的seed；探索解释只比较相同首seed子集，不与三seed均值混为同等证据。

## 公平预算、效率与边界

每臂1000次实际更新、3000R窗口同序，RS另1000S同序，meanR+1/3meanS、AdamW lr0.001/weight_decay0.0001、FP32、last不挑best、50步完整断点。所有窗口和已知身份标签保留，即使Pose全部缺失或gate为0也不跳过有监督窗口。候选pair曝光独立记录，额外S不等FLOPs或总pair量。

增强只改变原本有效的预测点，不补GT Pose或升级unknown；GT身份/框标签不变。扰动按seed/domain/epoch/预测UID/joint无状态生成，同观测跨窗口共享，同seed的R/RS和相应单因素组共享随机实现。特征预取2、LRU 256MiB，增强观测缓存上限4096条，避免重复解码和逐候选重复生成历史扰动。

沿用三比赛060/097/151各750帧、固定raw/PT Pose和956个检测断档proxy，S仅1048蓝四机位，1102排除。全部研究代码/bundle/权重/结果在物理D研究根，合成4K只引用G成品，不复制或新渲染。v8两项预训练及motion_R/RS结果只作明确来源的参考，不重新推理或冒充本轮新增训练。

## 事前判断

主要判断要求gated_RS同时超过同容量motion_residual_RS和原v8 motion_RS：AssA宏均至少+0.5点、至少2/3训练seed正、至少2/3留出比赛均值非负、HOTA均差非负、IDF1降不超0.5点。另完整比较gated_R、robust_RS以及两项预训练参考，单独报告合成边际作用，不能把结构改进自动算作合成收益。

全部fold/seed/负结果保留；这些是已观察过的三场短官方train比赛上的开发迭代，不是新的盲测、统计显著或真实五人制泛化证据。mask有用也不等于骨骼坐标有用。图像拟真/球衣颜色的因果效果本轮未被单独干预，不能归因；后续同运动外观配对另立协议。
