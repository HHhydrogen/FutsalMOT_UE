# 从第一次训练到现在：模型训练历史

更新：2026-10-28。本文是面向项目使用者的持续研究日记，不替代各轮冻结协议和原始结果。它回答：每轮训练了什么、为什么、用了哪些数据、实际成绩是多少，以及为什么转向下一步。完成、失败、中断、仅诊断和未来计划分别登记；从未运行的计划不写成训练成果。

## 先读懂这条路线

研究经历了三个不同任务，不能把它们当成同一个模型一直加训：

1. **检测器迁移**：输入RGB，学习球员框。Pose尚未参与。合成图像可能改善某些指标，但严格框定位和综合成绩也可能下降。
2. **Pose位置微调**：主要学习17个关节的二维位置，尝试让合成Pose帮助真实图像定位。早期检测分支也有变化，后改为固定检测、只训练Pose分支；几何覆盖改善并不保证身份跟踪改善。
3. **身份关联器学习**：检测器和Pose预测固定，训练一个小网络判断“这个候选是不是之前那个人”。现在大部分训练发生在这里，不是在训练新的检测器或Pose头。最近的截距校准只拟合每个模型一个标量，不增加SGD更新。

**当前已知结论**：系统的身份关联在部分开发范围优于固定预训练追踪参考；合成监督有部分平均补充收益，但Pose相对强运动参照的可靠增量、合成与真实监督等效、真实五人制泛化尚未建立。所有下降和失败都保留。后面的绝对成绩必须连同评价面板阅读。

## 数字、术语和参数怎样读

| 名称 | 通俗含义与单位 |
| --- | --- |
| R / S / RS | R为真实训练监督，S为合成训练监督，RS为两种监督共同训练；不能把额外真实R伪装为S。 |
| 图像曝光 | 一张图像被送入训练一次；重复3次计3次曝光，不是3张独立图像。 |
| 窗口曝光 | 一段历史观测和当前候选被用于关联学习一次；一个窗口可含多个候选pair，不等于一张图。 |
| 更新 / step | 优化器实际更新一次；一次前向、评价或读取检查点不算训练更新。 |
| seed / fold / 臂 | seed是训练随机种子，fold是留出比赛划分，臂是一个方法×数据×fold×seed的完整训练单元；多个seed不是多个独立比赛。 |
| AP / AP50 | AP评价检测或关节定位，须注明对象和数据；AP50与AP50–95不是同一指标。 |
| AssA / HOTA / IDF1 | 分别反映身份关联、检测与关联综合、身份匹配表现；表中均用百分数，越大越好。不是“准确识别了多少百分比的球员”的直接计数。 |
| IDSW | 身份切换次数，越少越好；短片中很少的切换数不能单独证明稳定收益。 |
| 开发验证 / 最终测试 | 开发数据可用于研究分析，观察后不能再称盲测；最终SNMOT-116/187及test包持续封存。 |

后续参数必须写实际值，例如学习率`0.001`、更新`1000`次、输入`640×640`、每步`3R窗口+1S窗口`、每臂`3000R+1000S窗口次`，不能只写“和之前一样”或“扩大若干倍”。动态拟合参数要给出拟合规则、每fold实际数值及来源文件；未知项标缺失。损失系数`0.333333…`的精确表达为`1/3`，属于确定系数，不是相对某个旧版本的描述。

结果主表先给每组**绝对成绩**，配对差值和95%置信区间作为补充保留。不能从一个差值反推出未经核验的绝对成绩，不能把多个显示位数的近似数运算后当实测精确值。

## 按时间发生了什么

以下阶段按研究问题排序；B1–B5为bbox轮次，P2–P10为Pose/关联轮次，名称相似不表示同一模型版本。日期仅写来源明确的完成日期，不把seed中的数字当训练日期。

### B1：先训练检测器，确认合成数据能否迁移（2026-10-22完成）

**训练什么**：从COCO预训练yolo11n继续学习球员框。ByteTrack配置固定，没有训练身份网络。**为什么**：先打通“合成数据→真实足球检测→下游追踪”的完整链。

真实train为060/097共300图；151的150帧作开发验证。S从合成v1冻结300图。seed20261021，输入640×640，batch4，SGD，5轮，每臂750更新，固定last.pt。B每轮600R、累计3000R曝光；C每轮300R+300S、累计1500R+1500S。首轮学习率等未在本汇总重新核得，不猜填默认值。两组独立真实标注数相同，真实曝光次数不同。

| 方法 | 检测AP50–95 | HOTA | IDF1 | MOTA | IDSW |
| --- | ---: | ---: | ---: | ---: | ---: |
| COCO预训练 | 62.74 | 74.32 | 89.22 | 82.51 | 4 |
| B：真实训练 | 65.70 | 74.86 | 90.68 | 84.87 | 5 |

**结果如何理解**：C部分关联量改善，严格定位与综合追踪下降，不能说合成全面有效。C首次因电脑重启在第1轮后中断；失败独立保留，随后从原始权重执行完整750步。来源：[首轮报告](PRODUCTION8_PILOT_RESULTS.md)，原结果`D:/projects/FutsalMOT_Research/comparison/production8_pilot_report.json`。

截至2026-10-28，有界错误分解和唯一训练R截距因素已经闭合，未建立整体追踪能力进一步上升；原主参照保持。下一研究方向是核训练候选与自由追踪状态的差异、历史错误传播，再根据证据只选一个因素。它目前是方案，不是已运行训练。不能把历史unknown行全部归为网络排序差，也不能由本轮直接推出扩大模型或扩充合成数据必然有效。

所有已有12场都属于开发范围。Pose增量、合成监督增量、资源替代和整个系统优于某个参考是不同命题；最终测试持续封存。历史预训练模型的既有训练知识、各轮R/S曝光预算、有效pair数量、标注成本和FLOPs分别陈述，不互相冒充。
