# v9训练前诊断：Pose拖累、拟真度与队服

2026年10月25日。固定v8模型、预测缓存及标签规则，只做CPU诊断，没有新增正式训练。最终116/187及test包未读取。以下统计不能冒充新追踪结果或单因素因果结论。

## 表示和缺点

三折、三seed的v8 motion_RS/pose_RS，在原train R/S池及每场额外1000个稳定SHA均衡留出窗口上比较。留出窗口使用可信GT身份连接的teacher-forced历史，因此分类指标不等于自由追踪指标。

| 数据 | motion_RS窗口BCE | pose_RS窗口BCE |
| --- | ---: | ---: |
| train R | 0.1462 | 0.1675 |
| train S | 0.0920 | 0.1265 |
| 留出窗口 | 0.1941 | 0.2569 |

Pose模型在见过的R、S上也更差，不能只解释为合成外观域差或“训练拟合好、验证过拟合”。高维输入、缺点和优化干扰是待检验解释，不能仅由BCE断定根因。

固定Pose模型的留出窗口输入扰动：

| 推理输入变化 | 窗口BCE | pair AUC |
| --- | ---: | ---: |
| 原输入 | 0.2569 | 0.9674 |
| 仅保留几何mask相关通道 | 0.2403 | 0.9752 |
| 移除mask相关通道，仅坐标 | 0.2818 | 0.9638 |
| 移除全部Pose通道 | 0.2638 | 0.9773 |
| 移除头部五点相关通道 | 0.2551 | 0.9712 |
| 20%关键点缺失 | 0.3216 | 0.9515 |
| bbox尺度σ=0.03坐标抖动 | 0.2609 | 0.9664 |
| 缺失与抖动同时 | 0.3245 | 0.9507 |

这里是固定权重的反事实敏感度，不是重训消融。缺失在该强度下比小抖动更伤；移除通道会造成分布变化，不能由单表证明哪些特征训练后最优。

## 自由追踪状态

预先固定seed20261024的三场motion_RS参考：观察器均逐字节复现原MOT，未使用GT。实际参与MLP的7588/8336/4803个候选中，缺少6个共同几何有效肢体点的比例约76.7%/66.8%/69.4%；候选包括错误或背景匹配，不能称为正确目标Pose缺失率。

Pose模型在同一运动参考状态下改变1055/872/279个候选的0.5接受判定，说明输入差异已能影响决策。最近两个实际历史时间间隔均为native 0.04秒，当前观察不支持将“末两条历史间隔变化”当作主要原因；训练teacher-forcing与自由追踪仍有其他差异，尚未全部隔离。

## 图像域差与“拟真”

预先选择144个可信人物裁剪：72R、72S，三真实比赛/四合成机位均衡；同尺度描述，前60%时间训练探针、后40%时间留出，合成四机位共享时间划分。没有复制4K图到研究目录。

- 颜色直方图、灰度梯度/纹理分别训练的小型线性域探针，在48个时间留出裁剪上AUC均为1.0；纹理探针准确率约97.9%。说明这批样本可轻易区分来源，不是拟真度评分，也不是独立新比赛的域分类验证。
- 可见差异包含室内球场/室外草地、队服、光照、视频模糊压缩与渲染清晰度。特征统计不能分清材质真实程度、原生像素密度或成像链各自的因果作用。
- 同运动红棕地板裁剪的颜色探针“合成概率”均值从约0.979降到0.464，纹理探针仍约0.887。这只是既有配对图上的手工特征响应，不证明改地板改善Pose或追踪。
- 在可信匹配且已有几何预测的合成肢体点上，投影PCK@0.1 bbox高约97.9%–99.0%；预测点覆盖约80.2%–92.4%。它是条件投影吻合度：原visibility未知、骨中心/表面锚点不等于真实COCO可见点，不可称为全部点精确准确率，也不能与真实足球无GT Pose的情况直接比较。

当前关联器仅输入bbox和预测Pose，没有RGB或球衣颜色。外观差异可能经上游检测/Pose、碎框与样本难度间接传递，不能说关联器直接记住绿色球衣。S在清晰可信目标上的投影吻合并不差，也提示不能把所有失败都归于“渲染不像真实”。

## 球衣颜色

72个合成人物裁剪包含35个L队和37个R队样本，不是72个独立球员。两队上身HSV直方图均值余弦约0.9975，抽样配色高度接近；背景和光照也影响统计，不能据此声称已经逐资产核对所有材质。

后续数据应队内统一、队间可区分，跨seed变化队服颜色/材质；同一序列保持身份外观稳定。同运动配对可进一步隔离配色及成像退化的作用，不能每帧或每人独立乱色。本轮冻结缓存不换球衣，不启动新UE渲染；拟真改进须另立数据版本和受控实验。
