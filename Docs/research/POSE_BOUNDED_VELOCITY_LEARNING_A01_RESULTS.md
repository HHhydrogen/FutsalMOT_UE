# 有界变化编码单因素验证完整结果

更新：2026-10-27。27臂训练、513项追踪/评价/自动分析和独立终验a02已完成，实际生产进程退出。最终SNMOT116/187及test包继续封存。

本轮没有建立有界历史变化编码相对强运动关联器的可靠增量。七场上，新编码相对强motion的AssA均差为−0.0582点，95%t区间[−0.2245,+0.1080]；相对原Pose编码为−0.0500 [−0.2731,+0.1731]。新T_RS模型开启相对关闭自身Pose分支为+0.0106 [−0.0524,+0.0736]。这些是固定训练面板、已观察开发比赛中的描述，不证明两方法等效，也不证明所有Pose利用方式无效。

## 实验回答什么

T_R只用同序3000R；T_RS在同3000R基础上另加1000个平衡S窗口；T_shuffle_RS曝光相同，从训练首步用允许池内兼容预测供体打乱形状对应。三组各三fold、三seed、1000更新。真T表征替换仅将34个历史均值通道及其基础R标准化换成按真实时间差和训练R尺度归一、每关节二维向量范数≤1的历史速度，其余160通道、原质量gate、网络和初始化不变。形状打乱控制另外重算完整坐标、距离及速度描述，保持motion24通道、mask/coverage、原gate和三组共享标准化，不将它误称为只打乱34列。

原强motion、原gated及同名义容量motion_residual_RS为来源核验后的完整参考。后者七场缺失63项评价本轮补齐，新增优化更新0。名义参数相同不等于有效统计容量相同。新T_RS和shuffle的推理关闭只关闭各自模型末gate，回到各自学习到的运动分支；不能称它们共享同一个运动模型。旧motion_residual没有Pose分支，不属于该开关操作。自然推理从不打乱Pose。

## 如何解释

1. 额外S的平均点估计在三面板均为正，七场为+0.2643点，但区间[−0.2472,+0.7758]仍覆盖下降。该比较仅回答当前表示中合成窗口的补充作用，不证明合成等价真实、25%人工标注节省或Pose自身优于运动。
2. 新编码没有在原三场、旧两场及七场共同优于原编码或强motion。旧两场对强motion仅+0.0117点，原三场−0.4811点，七场−0.0582点；不能挑旧两场微正值支持稳定Pose收益。
3. 真实形状训练相对打乱组七场+0.1164点，区间[−0.0522,+0.2851]。两组都关闭Pose后仍差+0.0613点，说明训练干预也改变了学习到的运动分支/正则化；不能把整个差值归于推理时Pose几何。供体干预覆盖并非100%，原质量gate仍含Pose质量信息。
4. 新T_RS自身开启−关闭在七场仅+0.0106点，IDF1点估计反而−0.0229点。仅用AssA小幅正值不能称实际身份连续性已稳定改善。推理关支路不等于从首步移除所有Pose信息的训练控制。
5. 本轮未支持“这一项有界历史变化替换已经解决增量不足”的主张。尚无人工关键点真值，不能将失败定位为数据集拟真、Pose估计误差、网络容量或关联策略中的某一个原因。
