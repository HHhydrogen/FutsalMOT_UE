# R候选集合监督：结果前冻结的追踪评价规则

冻结状态：已选单因素是R窗口损失由known-pair BCE改为含固定无匹配logit 0的候选集合CE；正式训练与追踪尚未开始。本文件先于数值准入和正式训练冻结，不能据局部结果改比较、阈值、种子或评价范围。

## 数据与固定条件

新模型为R/RS × game4/game6/game9 × seed 20261024/20261025/20261026，共18模型。每模型沿用该fold唯一1000窗R池和原曝光表，每步3个R窗、1000更新、累计3000个R窗口曝光；RS每步另1个原v10 balanced S窗、累计1000个S窗口曝光，S仍用原known-pair BCE且系数为1/3。网络194→64→32→1、ReLU、14593可训练参数、FP32、原base-R normalizer与每seed原初始化保持。只有R损失函数改变。原强motion模型的R/RS和上一轮自由状态R来源对齐模型均作为冻结参照；不重训、不校准、不选择检查点。

追踪18个新模型各在其fold的原heldout 1场、旧外部2场及七个已观察开发片段上运行，共180项。旧180项只读复用。最终SNMOT116、SNMOT187与test包封存。原阈值保持绝对值：high 0.25、low 0.10、new 0.25、buffer 30、high-match 0.80、low-match 0.50、unconfirmed 0.70、fuse-score true；dt≤1.2秒、面积比0.25至4、归一中心距离≤2、模型概率0.50。推理继续原sigmoid概率与阈值0.50，不将候选softmax分数引入tracker。

## 事前比较

| 比较 | 解释 |

| 新集合CE-RS − 上轮对齐BCE-RS | 主要比较：同一R来源/同一S条件下改变R损失 |
| 新集合CE-R − 上轮对齐BCE-R | 纯R重复比较 |

各方法先报告原3场、旧2场、七场三个面板内的绝对AssA、HOTA、IDF1、DetA、MOTA；AssA为主指标，其余为次指标。五比较族 × 三面板 × 五指标共75个未校正描述区间，完整保留正、负、零、null及每场/fold/seed值。交互对比只由已报告的绝对方法值计算，不能反推出或伪造独立模型成绩。

每场先平均该场所有匹配fold/seed差值，再让比赛等权。原3场每场3个seed；旧2场和七场每场3 fold×3 seed。95% t区间自由度依次为2、1、6；比赛级bootstrap固定10000次、Python `random.Random`（MT19937）seed 20261028，每次以`randrange`有放回抽取该面板比赛数，使用线性分位数，并做逐场留一敏感性分析。seed/fold/任务单元不是独立比赛。不设δ、等效或非劣效通过线；CI包含0不能表述为“相同”。

全3690可信gap只读原账本，不重登记；tracking进程只看不含GT坐标的公共receipt，endpoint GT只供独立metric进程。gap结果单列，缺事件为null；gap不是物理遮挡证据。候选和旧参照间按同一来源配对描述，不将gap数当独立比赛。

## 解释边界

已知候选CE把unknown排除在softmax集合外；unknown可能含真实目标，因此固定null项只表示当前known集合内“无已知匹配”，不等价于物理场景无人可匹配。R窗口来源本身已出现anchor偏离代理与无known-positive窗口；本实验不筛窗、不改标签、不改anchor资格，若性能变化只归因于整套R损失政策差异，不能拆成某个标签子类的因果效果。

只有18臂、180新追踪、独立分析及终验全部完成且所有进程真实退出，才报告性能。候选训练小张量、数字准入或首1000臂不构成追踪提升。若新模型未回到原strongmotion参照附近，也不能据单次负结果宣布该因素绝对无效；完整报告保留所有种子和失败。12场全属已观察开发范围，不称盲测、泛化或SOTA。
