# 30秒配对数据的下一轮实验

本页是基于完整v4结果制定的方案，尚未冻结、未训练。v4原六臂与所有负结果保留；新布局源码不冒充原冻结身份。

## 本轮能回答什么

同3000次真实图像曝光，v4加入1000次合成曝光后AssA平均仅+0.26444个百分点，1/3训练seed为正，未达到事前门槛。混合臂与预训练Pose的登记追踪指标相同。因此现阶段只能说明当前混合方式没有形成稳健的边际收益，不能把原预训练Pose相对bbox的提升归给合成数据。

两个已观察到的瓶颈需要分别处理：原120帧试产在640输入下人物框高中位约27.33像素，真实样本约138.27像素；预训练Pose附件仅覆盖1675/6901个固定检测。前者可能影响位置监督质量，后者限制Pose变化能进入关联的范围；它们尚未被证明是全部负结果的原因。

## 下一轮顺序

1. 只读30秒数据的bbox/Pose/源帧元数据，统计人物尺度、有效位置点、相机及交互覆盖。先核验可构建的裁剪范围，不扫媒体hash或重复渲染；不能直接把旧120帧的尺度统计当成30秒测量值。
2. 固定一份train源帧/相机表，构建仅位置监督的尺度匹配候选。裁剪和缩放必须同步变换bbox/Pose与有效点；unknown保持unknown，不生成虚假visible/遮挡标签。不依据模型成败选样，1102继续synthetic_dev。
3. 一次冻结R3、R3S蓝地板、R3S红棕地板三臂及三个训练seed。两种S复用相同运动、身份、相机、源帧和裁剪表，仅地板不同；每臂1000更新、相同3000R且同序，混合各额外1000S，分域loss权重沿用1/3。计算量、有效监督点和实际曝光分别记录。若要复用旧R3，只能明确列作历史参考；新的严格配对结论使用新协议下的R3。
4. 仍用原450帧raw检测、lambda=.1及几何规则，不改匹配阈值来追求正结果。先报告COCO开发位置质量及Pose附件覆盖，再报告AssA/HOTA/IDF1/IDSW；同时比较混合减R3、混合减预训练。采用原进步门槛并保留全部seed。

真实预训练模型需在相同评价链中作为独立参考，不能把“减轻继续训练退化”写成超越预训练。若位置AP提高而附件覆盖或关联无变化，优先分析接口覆盖与运动信息瓶颈；若地板两臂没有区别，如实记录视觉因素在该设置下未显示作用，不继续筛比例。

## 论文主张边界

30秒配对数据能够支持“同运动下分离视觉条件”的控制，不能单凭4K、四机位、COCO17或地板颜色宣称首创。交互信息量与视觉多样性的完整对照还需要更多独立运动源、持续交互及比赛隔离的真实开发证据；当前两seed配对、单game9开发片段不足以支持跨比赛或真实五人制泛化。
